algoritmia 1 - sesion 03

en esta sesion se realizaron ejercicios en pseint para practicar los ciclos, las repeticiones y la organizacion de los programas.

--------1 cajero del parqueadero

se realizo una prueba ingresando los valores 4000, 8000, 2000 y 0. el programa fue sumando los valores hasta que se ingreso 0 para terminar.

| valor ingresado | total acumulado | carros |
|---:|---:|---:|
| 4000 | 4000 | 1 |
| 8000 | 12000 | 2 |
| 2000 | 14000 | 3 |
| 0 | 14000 | 3 |

resultado final:

carros atendidos: 3

total recaudado: $14000

-------2 la piramide

se realizo una piramide con una altura de 4 filas. en cada fila se fueron agregando mas asteriscos y quitando espacios.

-------3 arbol de componentes

se realizo un ejemplo de como se puede organizar una tienda online por partes.

la pagina principal tiene una barra de navegacion, categorias, productos y un pie de pagina. tambien se identificaron los elementos que se repiten, como las tarjetas de productos y categorias.

---------aprendizaje

con estos ejercicios practique el uso de ciclos en pseint, la realizacion de pruebas de escritorio y la organizacion de una pagina web por componentes.
