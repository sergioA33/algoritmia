semana 2 - algoritmia

ejercicios

en esta semana se realizaron cinco ejercicios en pseint para practicar el uso de condiciones, operadores logicos y estructuras de decision.

------1 semaforo----------

el ejercicio revisa la cantidad de unidades disponibles y muestra un mensaje dependiendo del resultado.

| unidades | resultado |
|---:|---|
| -2 | error |
| 0 | rojo: agotado |
| 5 | amarillo: pedir |
| 15 | verde: todo bien |

--------2 bisiesto------

el ejercicio permite ingresar un año y comprueba si es bisiesto. para esto se utilizan las reglas de divisibilidad entre 4, 100 y 400.

| año | resultado |
|---:|---|
| 2024 | es bisiesto |
| 1900 | no es bisiesto |
| 2000 | es bisiesto |
| 2023 | no es bisiesto |

------3 parqueadero-----

el ejercicio calcula el valor que debe pagar un vehículo según el tipo y el tiempo de permanencia. también tiene en cuenta los primeros 15 minutos gratis, el máximo diario y el descuento por presentar factura de compra.

| vehículo | minutos | factura | resultado |
|---|---:|---|---:|
| carro | 10 | no | $0 |
| carro | 60 | no | $4.000 |
| moto | 90 | no | $4.000 |
| carro | 480 | sí | $15.000 |

-----4 validar registro---

el ejercicio solicita la edad y pregunta si la persona acepta los términos. el registro se realiza cuando cumple las dos condiciones: tener 14 años o más y aceptar los términos.

| edad | respuesta | resultado |
| 15 | S | registro exitoso |
| 13 | S | no puedes registrarte |
| 18 | N | no puedes registrarte |

------5 validar edad-------

el ejercicio solicita una edad y comprueba que esté dentro del rango permitido, desde 0 hasta 120 años.

| edad | resultado |
|---:|---|
| -5 | edad invalida |
| 0 | edad valida |
| 25 | edad valida |
| 120 | edad valida |
| 140 | edad invalida |

------archivos-----------

los ejercicios se encuentran guardados en archivos .psc y las capturas de los diagramas de flujo se encuentran en la carpeta imagenes.

-----aprendizaje--------

con estos ejercicios practique las condiciones simples y compuestas, los operadores logicos, las estructuras si y segun, y la realizacion de pruebas de escritorio para comprobar los resultados.
